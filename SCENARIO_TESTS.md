# Scenario Tests (PST) — YouTube Studio Hub

Метод: `Docs/session-notes/SCENARIO_TESTING_STANDARD.md`. Систематический
grep всех `@chat.function` имён против текста `tests/*.py`.

## Прогон 2026-08-19

Все 25 `@chat.function` уже вызывались напрямую хотя бы раз в
`test_smoke.py`/`test_panels.py` — по имени покрытие 100%. Но покрытие "по
имени" не гарантирует правдоподобные многошаговые сценарии: единственный
существующий тест `disconnect_account` (`test_disconnect_account_removes_it`)
проверял только удаление самой записи аккаунта, никогда не проверял
побочную очистку данных — то есть именно то место, где нашёлся баг.

Составлен `tests/test_pst_coverage.py` — 5 сценариев вокруг реального
жизненного цикла: создатель сохраняет идеи → отключает аккаунт → идеи
должны исчезнуть; агентство с двумя аккаунтами → отключение одного не
должно тронуть идеи другого; аккаунт без закешированных `channel_ids`
(старая запись) должен отключаться без ошибки; несуществующий
`account_id` → ошибка; идеи, созданные через AI-путь
(`generate_content_ideas`), тоже должны корректно чиститься.

### Найден и исправлен реальный баг

**`disconnect_account` никогда не удалял сохранённые идеи аккаунта.**
`accounts.disconnect()` искал документы `youtube_content_ideas` по
`where={"account_email": email}`, но ни `save_content_idea`, ни
`generate_content_ideas` никогда не записывают поле `account_email` на
документ идеи (только `channel_id`/`title`/`target_keyword`/`rationale`/
`status`) — запрос всегда возвращал 0 строк. Функция открыто обещает в
своём описании: *"Its local YouTube Studio Hub data (saved ideas) is
removed"* — но фактически идеи оставались в хранилище навсегда после
отключения аккаунта. Ни один существующий тест это не проверял (только
удаление самой записи аккаунта), поэтому баг был невидим при 29/29
зелёных тестах.

**Исправление:** `accounts.disconnect()` теперь ищет идеи по
`channel_id ∈ account.channel_ids` (тот же ключ join, что уже
использует `account_for_channel()` в этом же файле), а не по
несуществующему `account_email`. `youtube_settings` намеренно исключён
из очистки — это один общий документ `scope="app"`, не привязанный к
аккаунту, поэтому там нечего чистить по аккаунту.

### Итог

5/5 новых PST-тестов зелёные, полный набор 34/34 (было 29). Код
приложения изменён (`accounts.py`) — коммит + push.
